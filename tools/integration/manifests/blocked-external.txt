# a service, a registry, or a toolchain this environment does not provide, and
# they express that as a connect that never completes — i.e. as a timeout.
#
# A file listed here is classified `blocked-external` INSTEAD OF `timeout`, and
# ONLY when it times out. It still runs, it is still not a pass, and nothing is
# verified by it. The point is to stop a bucket named "mbun hangs" from hiding
# the files where mbun actually hangs: 51 of the 107 timeouts in the 2026-07-20
# baseline round were of this kind (see issue #4).
#
# Rules for this list:
# - Only add a path after triaging it and naming the missing dependency below.
# - Never add a file that hangs for a reason inside mbun.
# - fnmatch patterns, matched against the repo-relative path.
#

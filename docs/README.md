# Public documentation

This directory is intentionally minimal in the public source distribution.

The public entry point is the repository [README](../README.md), which documents:

- source-only build requirements;
- reproducible unit, integration, and Bun-native test commands;
- the current project status and its limitations;
- the repository directory layout.

Internal development plans, agent instructions, private work logs, and local research notes are not part of this public project copy.
